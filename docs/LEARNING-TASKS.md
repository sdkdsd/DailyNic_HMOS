# 学习通待办（2026-11-12）

用户限定范围：未交作业、待考考试、截止时间，在首页和待办显示，支持主动联网刷新。不做章节任务点、通知、资料、签到、答题、自动交作业或后台同步。

## 实现

- 首页/待办的“学习通 → 联网刷新”以及功能页“学习通作业与考试”打开同一页面。本人在官方 HTTPS 页面登录，分别打开作业/考试列表，整页读取、预览后确认更新。
- 临时 ArkWeb 会话，不提取 Cookie、不保存密码、不做原生 HTTP 登录或凭据桥接。固定脚本仅识别准确的官方来源及列表路径，读取条目 ID 和名称/课程/状态/剩余时间；不返回完整 HTML、隐藏输入或带会话参数的 URL，不自动打开试卷和作业详情。
- `LearningTasks.ts` 负责严格验证、状态分类、北京时间与来源 ID 去重；`LearningScript.ts` 为限定范围的 DOM 脚本；`LearningStorage.ets` 独立原子保存 `learningTasks.json`；`LearningTaskList.ets` 在首页/待办展示。
- 手动课表/考试/待办文件不变。学习通事项只读，平台已提交、待批阅、已结束等状态不再显示为待办，不将“已结束”说成“已完成”。未知状态或部分条目损坏拒绝整次更新。
- 缺失条目可能在其他页：只更新已读取 ID，不以缺失推断完成/删除。每条显示读取时间；未读到的旧项保留旧状态。当前仅用于同一账号；不提供跨账号切换/聚合。
- 剩余天/小时/分钟只能估算截止时刻，界面明确写“约”，统一北京时间；没有期限不猜测。完整精确截止时间须待实页核对。
- 写入前核对预览基线及5分钟有效期，验证暂存文件内容后替换。读取失败、空列表、格式变化、磁盘写入失败均保留旧数据；损坏缓存拒绝覆盖并显示说明。

限定范围仅未交作业、待考考试、截止时间，首页/待办显示和主动联网刷新。sust.6在本人同一次登录中实测：读取保存60条作业（2条未提交）、52条考试（5条未交），考试重复读取保存数量不变，待办滚动显示7条不重复。所有待办本次未提供期限，明确提示期限未知，不断言仍可参加/提交。原课表、手动考试及作业缓存跨sust.6安装保留。

全部58项Node测试通过（学习通9项），实际ArkTS/HAP及个人签名验签通过。最终检查发现首页同ID旧行仍显示旧读取时间，待办新页正确；sust.7改用包含任务内容的渲染键，已打包但按用户要求本轮不再安装/重启，手机仍为sust.6。不要把sust.6结果当成sust.7真机验收。来源和哈希见docs/DELIVERY.md，详细边界见docs/LEARNING-TASKS.md。

- 9项学习通合成行为测试覆盖DOM元数据、来源隔离、状态更新、重复刷新、缺失项保留、累计小时、未交考试、加载时间锚定、预览冲突及原子写入失败保护。主机不替代手机验收。
