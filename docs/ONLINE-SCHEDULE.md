# 主动联网获取课表

2026-11-12 用户明确最终目标是可以联网获取和刷新，不接受固定预填或逐门录入。此前“优先文件导入”的主流程决定由本说明替代；文件导入仅作备用。不把本人课表、账号或 ID 编进 HAP。

## 使用流程

1. 核对个人作息后，在课表菜单选择“同步在线课表”。应用打开学校 HTTPS 课表入口。
2. 本人在学校网页登录；选择学期、全部教学周和学生课表，点“读取当前课表”。切换班级课表，再读取一次。每次读取整张表，无需逐门输入。
3. 核对第一教学周周一（随新学期校历调整）、预览学生与班级合并结果；班级选修差异应本人核对。用户已明确本次班级体育就是本人体育，不能因名称没有网球后缀漏掉它。
4. 确认后首次建立专用在线学期，同一学期再次读取则更新这个学期，并显示更新前后课程与增减数量。可选择设为首页/卡片默认。没有定时后台刷新；离线继续显示最近保存数据。

## 实现与数据保护

- `GetSchedule.ets` 使用 ArkWeb `incognitoMode: true`；只允许 bkjw/login/my.sust.edu.cn 的 HTTPS 导航，将实际观察到的 bkjw/login 主框架 HTTP GET 跳转升级到 HTTPS（最多8次，不重放POST），拒绝其他地址、证书错误、混合内容和本地文件访问。普通说明文档 WebView 不改变。
- 学校登录在网页内正常完成；没有自动填密码、Cookie 导出/保存、原生 JavaScript proxy、网络凭据桥接或后台 HTTP 登录。固定读取脚本核对实际HTTPS教务域名与/eams/目录，只接受完整课表控件和表头，读取可见表格及类型/周次/学期控件，不读取完整 HTML、脚本、隐藏输入或账号链接。
- `SustOnline.ets` 解析实时网格和课程列表，不固定学期、课程代码、教师、教室或周次；按真实 rowspan 映射星期/连堂。静态校历草稿仅供首次核对，不代替以后学期的首周输入。
- 学生/班级课表同学期、全周核对，教室代码后缀规范化后去重；具体停课先排除。冲突、空表、未知格式、未确认晚课拒绝整次更新。
- `OnlineSchedule.ets` 预览不写盘。专用在线学期保留上次学校课程快照，刷新保留不冲突的手动新增；已有学校课程被本地修改/删除时拒绝覆盖并提示核对。首次和更新都由用户确认。保存前重新验证作息和本地版本，失败保留旧文件及缓存。
- `ScheduleStorage.ets` 在同一原子保存中更新课程、来源和默认学期；重复获取不无限追加学期。其他离线/文件学期保留。五分钟读取批次超时或读取失败须重新读取，不拼接失败前的旧批次。
- 课程改变后已有系统日历提醒需主动重新生成，不承诺系统定时刷新或推送已测。
