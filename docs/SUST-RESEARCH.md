## 后续集中需要的非敏感材料

待用户方便时，一次性补齐：

1. 身份类型（本科/研究生；不同系统可能不同），当前学年学期；官方西安校区校历及完整作息表，含夏冬季适用日期、节次上限、午休/晚课安排和放假调课通知。
2. 用户在自己的安全浏览器从上述官方门户登录，只打开课表、考试等只读页面。记录“门户 → 教务 → 我的课表/考试”的菜单路径，以及最终页面的域名和不含敏感查询参数的路径。
3. 脱敏的课表/考试页面结构或官方导出文件样例：保留表头、星期、周次、节次表达式、学期名称、时间格式；遮去姓名、学号、成绩、身份证、联系方式等信息。截图可用于确认布局；解析器开发更适合已脱敏的导出表格或 DOM 片段。
4. 单周、双周、跨节连堂、周日课程及调课至少各一个脱敏样例。若没有真实例子，不人为声称覆盖这些接口格式。

**不要发送密码、Cookie、令牌、验证码、带会话参数的完整 URL、完整 HAR 或 DevTools 请求头。** 页面“另存为”也可能包含隐藏 token，未脱敏前不要上传。登录和验证由用户自行完成；如后续确需会话持久化或跨页面传递，必须先说明目的、最小权限、存储与清除方式，再取得明确同意。

## 接入方案

优先尝试学校提供的导出/打印文件 → 用户选取本地文件 → 纯本地解析 → 展示预览和差异 → 用户确认写入本地。无需搬运学校会话，也能保留课表卡片和提醒。只有存在可证实且允许使用的只读接口时，才设计登录后读取。

自动同步、后台刷新和成绩获取均没有实现。选课目录、作业导入、教室查询需要各自证据，不会因为课表接口可用就宣称一并适配。没有对应接口时继续显示“尚未实现”，保留官方网页和手动待办作为替代。

涉及提交选课、退课、预约、支付、委托、信息修改、修改账号安全设置等操作，必须另行取得用户确认。本次没有执行这些操作。
