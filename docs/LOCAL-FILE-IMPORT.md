# 教务课表本地文件导入

本版本新增电脑端转换器 `scripts/sust_import.py`，手机端在课表菜单选择转换后的 JSON，查看完整课程预览后再确认追加。它不是在线同步，不保存学校账号凭据。考试文件导入仍未实现。

## 输入与来源

2026-11-12 在用户本人登录的官方教务页面完成只读核对：我的课表 → 学生课表/班级课表 → 全部教学周。班级课表比学生课表完整，用户要求用班级补充，并明确确认班级体育也应加入。

主页面只有打印入口；打印视图有导出入口。点击官方导出时内置浏览器超时，**没有取得并验证学校下载的 Excel/其他导出文件**。本次实际数据来自已显示的 DOM 表格，必要字段转录到本地 JSON，并按读取结果核对；不称为官方导出下载成功。原始账号信息、网页脚本、隐藏字段和会话参数不保存到这些输入文件。

转换器支持：

- UTF-8 的已渲染课表 HTML：须包含 `manualArrangeCourseTable` 及课程列表；仅解析静态表格，不执行脚本。HTML 路径通过合成结构测试，尚未用学校官方下载文件验收。
- 可见表格 JSON：`kind`（学生课表/班级课表）、`week`（全部）、`semester`、`rows`（单元格 `text/rowspan/colspan`）、`catalog`（含完整表头）。本轮以真实页面字段转录文件走通；JSON 不是学校接口响应格式。
- 不支持 PDF、图片识别、Excel 二进制文件，也不把页面源码里的 JavaScript 当作课程数据执行。

## 使用

在电脑已有 Python 中执行，无需安装依赖。输出必须是不存在的新目录；个人文件放在 Git 忽略的 `private-data/`。

```powershell
python scripts/sust_import.py --student private-data/student-visible.json --class-table private-data/class-visible.json --semester '2026-2027学年1学期' --first-monday 2026-08-31 --weeks 20 --confirm-all-weeks --include-class --output private-data/import-new
```

两个输入必须确为同学期、全部教学周。JSON 的元数据会核对；HTML 打印页可能不带筛选控件，操作者须核对后传 `--confirm-all-weeks`，不得将单周表声明为全部周。`--include-class` 明确将班级补充列入待确认文件；可用重复的 `--exclude-code` 排除不属于本人的班级课程。

生成：

- `PREVIEW.md`：课程、星期、连续节次、完整周次、教室。
- `review.json`：班级补充、去重、冲突未导入、明确排除、停课及输入散列。
- `schedule-import.json`：与应用备份格式兼容的导入文件。带已确认的冬夏第1–8节作息及本学期20周校历；手机当前作息须一致。晚课不推算，出现超过已确认节次的安排就拒绝整个转换。

手机操作：先核对并保存作息 → 课表 → 导入和导出 → 选择 JSON → 查看预览 → 确认追加。追加后默认学期不变，可在学期管理中选择新的默认学期。检查全部课程再生成日历提醒。关闭预览或取消不写盘；确认时重新验证作息；存储失败不追加半批数据。**手机文件选择器、预览 UI 及实际导入仍待手机验收**。

## 解析与合并规则

- 严格核对星期一至星期日表头、第1–11节行标签与合并网格；星期日映射本地 `0`，节次取实际 rowspan，不按非空单元格顺序猜星期。
- 核对课程名、课程序号、教师与课程列表。支持课程名中的括号、多个教师、空教师、一格多门课、空格分隔周次，以及单双周表达式。单双周为合成用例覆盖，本轮页面没有实际单双周例子。
- 学生/班级共同安排的教室编号后缀正规化后去重。不同教室/教师或不同课程在重叠周、星期、节次的安排进入冲突清单，不覆盖学生安排。
- 页面明写的“停课”不当教室；只扣除对应课程序号、星期、节次的周次。不能由此推断其他课程或节假日的补课映射。
- 任何未知格式、无效周次、不完整网格或课程列表存在未安排课程，拒绝整个转换，不猜测。已有输出不覆盖。

主机验证：`python -m unittest discover -s tests -p test_sust_import.py -v`；应用逻辑、预览不写盘、确认时校验和失败保持数据由 `node --test tests/*.test.mjs` 验证。真实学生数据不进入测试样本或仓库。
