## 代码变更范围

- `CampusConfig.ets`：手动核对的作息与校历，写临时文件再重命名，每次卡片回调重新读盘。
- `CampusTime.ts`：纯日期/节次/周次逻辑，主机测试直接使用。
- `ScheduleSources.ets`：课时引用个人配置；`sust-xian-1` 备份带课时表并严格校验；不将旧中科大数据静默迁为陕科大数据。
- `Schedule.ets`、`Index.ets`、`CheckIn.ets`、`EntryFormAbility.ets`、课表卡片、`tools.ets`：统一教学周和课时来源，动态网格、清空示例课程、未配置提示。
- `GetSchedule/GetHomework/GetClassByName`：明确未适配提示。旧密码弹窗/桥接/自动提交脚本移除。未使用的中科大在线解析方法移除，原实现仍在 Git 历史。
- `Links.ets`、`Webview.ets`、帮助、关于、首次声明：只保留有证据的官方网页入口；凭据不进入应用；清楚区分上游和本 fork。
- 独立包名 `com.sdkdsd.dailynic.sust`，版本 `2.3.0-sust.1`；同步修改卡片添加、重启、桌面快捷方式。本 fork 的系统日历账户使用独立名称。
- 新增只读环境检查、构建入口与 HAP 身份检查脚本；忽略签名/凭据/私人文件；依赖版本和锁文件未升级。
