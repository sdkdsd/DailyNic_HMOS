## 本轮具体修复

- 日历：移除 500 ms 延时串联及未完成就提示成功；整批事件预校验，按实际周次生成，等待全部操作，失败清理新日历。只处理 `SustPersonal.*` 两个账户。主机桩不保证手机 CalendarKit 行为。
- 考试：统一北京时间，拒绝无效日期/相同起止/跨日；修改以一次存储替换旧记录；复制隔离草稿；默认编辑时间不再出现 24–26 点。
- 存储与备份：考试/课表/待办先写临时文件、关闭并重命名；缓存只在成功后更新。课表整批导入保留学期长度并分配新标识，失败不留半批数据。文档 URI 保留授权，读写检查完整性，中文按 UTF-8 处理。
- 待办：失败显示未保存；共享图片仅在最后引用移除且保存成功后删除，限定私有图片目录；相册 URI 通过打开文件描述符复制。
- 首页与卡片：修复刷新定时器重复、返回首页/配置页的数据刷新，以及开学前夜明日课程遗漏；卡片消息拒绝损坏/未知输入。
- 兼容性：target/minimum 为 API 23；保留原视觉，替换触发 API 26 新重载的圆形色块。未升级依赖、未改 LICENSE 和依赖锁文件。
